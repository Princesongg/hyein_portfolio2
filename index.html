WEBSITE ↗

DURATION

PROJECT BRIEF

딥티크의 감각적인 브랜드 이미지와 세계관을 온라인에서도 경험할 수 있도록 기획한 웹사이트 리디자인 팀 프로젝트입니다.

팀원들과 함께 브랜드·경쟁사 분석, 페르소나 및 고객 여정맵을 바탕으로 개선 방향을 도출하고, 사이트 구조와 페이지별 콘텐츠를 기획하여 디자인과 구현으로 연결했습니다.

WHAT I CONTRIBUTED

  • 팀원들과 리서치·문제 정의 및 사이트 구성 공동 기획
  • 조장으로서 프로젝트 진행 및 디자인 방향 조율
  • 메인 페이지 PC·모바일 UI 디자인 (영상 히어로 제외)
  • GALERIE 페이지 PC·모바일 UI 디자인 및 구현
  • 메인 페이지 코드 수정 및 화면 개선
  • SHOP 등 여러 페이지의 코드 수정·구현 참여 및 디자인 피드백

quick Q&A

Q1. 패션·리빙 디자인에서 UI/UX 디자인으로 분야를 넓힌 이유는 무엇인가요?

고등학생 때부터 미술을 배우고 패션·리빙 디자인을 전공하며, 시각적인 표현과 직접 무언가를 만들어내는 과정에 흥미를 키웠습니다.
평소 다양한 웹사이트를 보며 브랜드의 개성을 화면에 담아내는 방식에 매력을 느꼈고,
저도 보기 좋으면서 사용하기 편한 웹사이트를 직접 만들어보고 싶어 UI/UX 디자인에 도전하게 되었습니다.

Q2. 이전 경험에서 얻은 가장 큰 강점은 무엇인가요?

한국과 일본에서 다양한 고객을 만나며 상대방의 입장에서 생각하고,
상황에 맞게 소통하는 태도를 배웠습니다. 이러한 경험을 바탕으로 사용자의 관점을 이해하고, 팀원들과 유연하게 협업하려고 노력합니다.

Q3. DIPTYQUE 팀 프로젝트에서 어떤 역할을 맡았나요?

조장과 메인 UI 디자이너를 맡아 영상 히어로 영역을 제외한 메인 페이지의 PC·모바일 UI 디자인과 코드 수정을 담당했습니다.
GALERIE 페이지는 직접 디자인하고 구현했으며, SHOP 등 다른 페이지의 코드 수정과 팀원 간 디자인 방향 조율에도 참여했습니다.

Q4. 디자인할 때 가장 중요하게 생각하는 것은 무엇인가요?

브랜드의 개성을 살리면서도 사용자가 정보를 쉽고 편리하게 이해할 수 있는 구성을 중요하게 생각합니다.
시각적인 완성도와 가독성의 균형을 고민하며, 실제 화면에서 직접 확인하고 개선하는 과정을 중요하게 여깁니다.
